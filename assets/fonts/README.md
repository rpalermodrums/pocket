# Atkinson Hyperlegible Next

Unmodified variable upright font from the [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext), downloaded 2026-09-23. Designed for legible reading; bundled under the accompanying SIL Open Font License. This font is a website asset, not a Pocket runtime dependency. License trailing whitespace was removed without changing its text. See OFL.txt for authorship, reserved names and redistribution terms.
